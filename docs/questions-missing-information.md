# Questions / Missing Information

Чтобы сделать репозиторий полностью трассируемым до исходных документов, перед финальной публикацией нужно проверить следующие места.

1. **Исходные файлы диаграмм.** Если есть оригинальные PlantUML/BPMN-файлы, их лучше добавить в репозиторий вместо текстовых описаний.
2. **Точные JSON request/response.** Для части endpoint в текущем репозитории есть только описательная информация; нельзя безопасно восстанавливать отсутствующие поля по памяти.
3. **Фактическая схема БД.** Для полноценной ERD нужны исходные таблицы, PK/FK и ограничения.
4. **Точная таблица переходов статусов заявки.** В README показан жизненный цикл, но полный список разрешённых переходов необходимо сверить с исходной спецификацией.
5. **Точная версия API Pruffme.** Перед публикацией нужно сверить rate limit и конкретный формат Base64 с исходной документацией.
6. **Контакты кандидата.** LinkedIn, email, Telegram и ссылка на резюме намеренно не заполнены.
