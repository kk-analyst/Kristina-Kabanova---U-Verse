# Система лояльности

## Бизнес-контекст

Система лояльности позволяет студенту накапливать и использовать бонусные баллы, отслеживать историю операций и применять промокоды.

## Что проработано

- отображение текущего баланса;
- эквивалент баллов;
- срок действия баллов;
- история начислений и списаний;
- правила использования промокодов;
- ограничения использования баллов;
- аудит операций.

## Ключевые бизнес-правила

- 1 балл = 1 рубль в отображаемом эквиваленте;
- баллами можно оплатить не более 20% итоговой стоимости покупки;
- нельзя передавать баллы между пользователями;
- для одной покупки допускается один активный промокод;
- промокод не применяется к уже уценённому курсу;
- срок действия баллов — до 6 месяцев;
- история операций хранится до 12 месяцев.
